# Unity Demo – Emotionally Adaptive Avatar

Απλό 2D Demo στο Unity, όπου ένας Avatar αλλάζει χρώμα ανάλογα με τη συναισθηματική κατάσταση.

## Πώς ανοίγει
1. Κατεβάστε το repository από το GitHub.
2. Στο **Unity Hub**, επιλέξτε **Add project from disk** και ανοίξτε τον φάκελο `Unity-Demo`.
3. Χρησιμοποιήστε κατά προτίμηση την έκδοση **Unity 6000.6.6f1**.
4. Ανοίξτε τη Scene από το `Assets` και πατήστε **Play**.

## Χειρισμός
- **1:** Positive → Πράσινο
- **2:** Negative → Κόκκινο
- **3:** Neutral → Μπλε

## Κώδικας
- **EmotionManager.cs:** Διαχειρίζεται τις εισόδους.
- **AvatarController.cs:** Αλλάζει το χρώμα του Avatar.
